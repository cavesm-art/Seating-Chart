Seating Chart Builder

Runs only in this browser tab. Nothing is uploaded or stored, and this page is blocked from using the network. Student names disappear when you close or refresh the tab.

Load students

Load one or more CSV files; files are merged by student name. Row 1 must be the column headings and is never read as a student. Recognized headings: Name (or First and Last), Class, Accommodations, Sit with, Keep apart, Teacher notes. Other columns are ignored and never stored.

Priority: IEP/504 accommodations first, then Teacher notes, then student requests (Sit with / Keep apart). If a teacher note goes against a student request, the note wins. If a CSV has a Class column, it labels the chart automatically.

New to this? "Fillable worksheet" is a form you can type into and save as the student file. "CSV template" is for Excel or Sheets.

Add a classroom object

Boards, windows, doors, lab tables, sinks, cabinets and more. They show where students can and can't walk; they don't hold students. Windows and Doors are also used for "near/away from window or door" needs.

Selected object

Click an object in the chart to select it.

Tips

Drag a table by its title bar to move it, and click empty floor to deselect. Drag the Teacher desk marker to match your room, and add Door and Window objects. "Front", "near door" and similar needs are measured from them. Click any seat to mark it unavailable (broken chair, blocked by a cart).

Save the layout

Your room layout contains no student information. It is remembered in this browser automatically, and you can also save it as a file.

Which tables to fill first

Tier 1 tables are filled before Tier 2, then Tier 3. "Not used" tables stay empty. Example: tables 1, 3 and 5 in Tier 1 and tables 2 and 4 in Tier 2. Accommodations still win if they need a seat in a later tier.

Table size

Example: a minimum of 3 means no table is used with only 1 or 2 students.

How to fill tables

Past seating charts

Load a chart you exported earlier (Export CSV). The builder will move students to different seats and tables and give them new table mates. You can load several. Names are matched to your current students.

Mixing up never overrides IEP/504 accommodations or teacher notes.
